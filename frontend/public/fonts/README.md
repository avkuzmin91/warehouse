# Шрифты

| Файл | Что это |
|---|---|
| `UcC73...woff2` | Inter (latin / cyrillic), Google Fonts |
| `L0x5D...Pq3-OXg.woff2` | Roboto Mono v31, cyrillic-сабсет, Google Fonts, без изменений |
| `RobotoMonoCZ-latin-*.woff2` | Roboto Mono v31, latin-сабсет, **патченный**: статические инстансы 400/500 из вариативного шрифта, у глифа `zero` слэш в счётчике заменён одним чистым овальным отверстием (лицензия Apache 2.0 допускает модификацию) |

Зачем патч: у всех моноширинных шрифтов Google Fonts с кириллицей ноль перечёркнут
слэшем или содержит точку — на кеглях 11.5–13px это читается как 8/Ø
(номера документов, SKU). Чистый ноль от буквы O отличается формой: он уже и прямее.

Как воспроизводился патч (fonttools + brotli):
1. `instancer.instantiateVariableFont(font, {'wght': 400|500})` на latin-сабсете v31;
2. в глифе `zero` два контура-дырки (счётчик, разрезанный слэшем) заменены одним
   овалом по их общему bbox (4 on-curve точки в экстремумах + 8 off-curve, k=0.78),
   направление обхода — как у дырки; хинты глифа сброшены;
3. сохранение с `flavor='woff2'`.
