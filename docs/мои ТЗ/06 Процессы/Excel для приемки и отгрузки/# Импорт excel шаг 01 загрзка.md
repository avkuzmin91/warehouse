- # ТЗ: Шаг 1 — Страница импорта Excel (выбор шаблона + загрузка файла)

  ------

  # 1. Цель

  Реализовать страницу, на которой пользователь может:

  - скачать Excel-шаблон
  - загрузить файл
  - пройти базовую техническую проверку
  - перейти к следующему шагу (preview)
  
  На этом этапе **НЕ реализуется бизнес-логика и валидация данных внутри файла**.
  
  ------
  
  # 2. Точка входа
  
  ## Иконка запуска
  
  Добавить иконку: **Импорт Excel**
  
  Расположение:
  
  - панель фильтров
  - слева от кнопки **Создать**
  
  ------
  
  ## Поведение
  
  При нажатии:
  
  - переход на страницу импорта
  
  ------
  
  # 3. Роут
  
  ```
  /inventory/receipts/import/excel
  /inventory/shipments/import/excel
  ```

  ------

  # 4. Структура страницы

  Страница состоит из 4 логических блоков.

  ------

  ## 4.1 Хлебные крошки

  Отображать: Главная / Учет товаров / Отгрузки / Импорт данных из Excel

  Главная / Учет товаров / Поступления / Импорт данных из Excel

  ## 4.2 Описание:

  Загрузите файл Excel для массового создания операций поступлений/отгрузок (Зависит от страницы с которой запустили)

  ------

  ## 4.3 Скачать шаблон

  - Иконка скачивания шаблона

  ------

  ### Поведение:
  
  В зависимости от выбранного шаблона скачивается файл:
  Массовое поступление товаров.xlsx - для поступлений

  Массовая отгрузка товаров.xlsx - для отгрузок

  ------

  ### Требование:

  - скачивание должно происходить сразу (без перехода на другую страницу)

  ------

  ## 4.4 Загрузка файла

  ### UI:
  
  - поле с возможностью Выбрать файл с иконкой загрузки файла
  - Drag&Drop зона

  ------

  ### Подсказка:

  Перетащите Excel-файл сюда или выберите файл

  ------

  ### Поддерживаемые форматы:
  
  - .xlsx
  - .xls

  ------

  ### Ограничения:

  - максимальный размер: 20 MB

  ------

  # 5. Состояния загрузки

  ------

  ## 5.1 Нет файла

  - отображается зона загрузки

  ------

  ## 5.2 Загрузка

  - показывается progress bar

  ------

  ## 5.3 Успешная загрузка

  Показывать:
  
  - имя файла
  - размер
  - статус

  Пример:
  
  ```
  movements.xlsx
  1.8 MB
  Файл загружен
  ```

  ------

  ## 5.4 Ошибка

  Показывать текст ошибки

  ------

  # 6. Первичная валидация

  На этом этапе выполняется только техническая проверка.

  ------

  ## 6.1 Проверка формата

  Если формат не .xls / .xlsx:
  
  Ошибка:
   Неподдерживаемый формат файла

  ------

  ## 6.2 Проверка размера

  Если файл > 20 MB:
  
  Ошибка:
   Размер файла превышает допустимый лимит 20 MB

  ------

  ## 6.3 Проверка чтения

  Если файл не открывается:

  Ошибка: Не удалось прочитать файл

  ------

  # 7. Действия пользователя

  После успешной загрузки доступны кнопки:

  ------

  ## Проверить файл
  
  - основной CTA
  - переводит пользователя на следующий шаг

  ------

  ## Удалить файл
  
  - очищает выбранный файл
  - возвращает состояние "нет файла"

  ------

  ## Отмена

  - возвращает пользователя назад

  ------

  # 8. Переход на следующий шаг

  При нажатии "Проверить файл":

  Переход на:
  
  ```
  /import/excel/preview
  ```

  ------

  ## Передаваемые данные:
  
  - file_id (временный идентификатор файла)
  - template_type

  ------

  # 9. Требования к backend

  ------

  ## Загрузка файла

  Endpoint:
  
  ```
  POST /api/import/upload
  ```

  ------

  ### Ответ:
  
  ```
  {
    "file_id": "uuid",
    "file_name": ".xlsx",
    "file_size": 123456
  }
  ```

  ------

  ## Хранение:
  
  - файл сохраняется временно
  - привязывается к пользователю

  ------

  # 10. UX требования

  Обязательно:
  
  - простой пошаговый сценарий
  - крупная зона загрузки
  - понятные ошибки
  - минимальное количество действий

  ------

  # 11. Ограничения

  На этом этапе запрещено:
  
  - парсить строки Excel
  - проверять товары
  - проверять остатки
  - применять бизнес-логику

  ------

  # 12. Описание шаблона

  Названия колонок для шаблона:
  
  Дата (исправить формат дд.мм.гггг)
  
  Клиент
  
  Название
  
  ШК
  
  Цвет
  
  Размер
  
  Количество
  
  Статус
  Комментарий
  
  
  Для примера:
  
  Дата = 01.01.1991
  
  Клиент = Рога и копыта
  
  Название = Водолазка
  
  ШК = 123456789
  
  Цвет = Черный
  
  Размер = 44
  
  Количество = 500
  
  Статус = Ожидание приемки (в поступлении), Ожидание отгрузки (в отгрузке)
  Комментарий
  
  
  Ширина Пикселей в столбцах в excel:
  
  Дата = 75 пиикселей
  
  Клиент = 120
  
  Название = 120
  
  ШК = 120
  
  Цвет = 120
  
  Размер = 70
  
  Количество = 85
  
  Статус = 140
  
  Комментарий = 300
  
  # 13. Результат
  
  Пользователь должен:
  
  1. Открыть страницу
  2. Выбрать шаблон
  3. Скачать пример
  4. Загрузить файл
  5. Перейти к следующему шагу
