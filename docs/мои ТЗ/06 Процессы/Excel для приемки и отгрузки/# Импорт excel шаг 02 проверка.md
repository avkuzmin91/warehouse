# ТЗ: Проверка Excel-файла перед импортом

------

# 1. Цель

Реализовать единый этап полной проверки Excel-файла перед импортом данных в систему.

Проверка должна включать:

- проверку структуры файла
- проверку корректности данных
- проверку бизнес-логики
- проверку остатков
- поиск товаров и вариантов

Без записи данных в систему.

------

# 2. Общая логика

После загрузки файла пользователь нажимает кнопку:

**Проверить файл**

Система последовательно выполняет:

1. техническую проверку файла
2. проверку строк
3. проверку бизнес-логики
4. формирует итог проверки
5. показывает детализацию

------

# 3. Размещение

Проверка выполняется на странице импорта Excel.

------

# 4. Кнопка проверки

------

## Название

Проверить файл

------

## Поведение

После нажатия:

- запускается полная проверка
- показывается индикатор загрузки
- кнопка блокируется до завершения проверки

------

# 5. Состояние проверки

Во время проверки отображать:

```
Проверяем файл...
```

------

# 6. Этап 1 — Проверка файла

------

## Проверка формата

Допустимые форматы:

- .xlsx
- .xls

------

## Проверка размера

Максимальный размер:

20 MB

------

## Проверка чтения

Система должна проверить:

- файл открывается
- файл не повреждён

------

## Ошибки

Примеры:

- Неподдерживаемый формат файла
- Размер файла превышает лимит [лимит]
- Не удалось прочитать файл

------

# 7. Этап 2 — Проверка структуры

------

## Проверка обязательных колонок

## Обязательные колонки

- Дата
- Клиент
- Название
- ШК
- Цвет
- Размер
- Количество
- Статус
- Комментарий

------

## Ошибка

Если структура некорректна:

```
Неверная структура файла
```

------

## Поведение

Если структура файла неверная:

- дальнейшая проверка НЕ выполняется

------

# 8. Этап 3 — Проверка строк

Проверяется каждая строка файла.

---

# Нормализация данных

Перед проверкой строк система должна:

- удалить пробелы по краям
- убрать двойные пробелы
- выполнять сравнение без учёта регистра
- привести значения к единому виду

Примеры:

- "черный"
- "ЧЕРНЫЙ"
- " Черный "

должны считаться одинаковыми.

------

# 9. Проверка даты

Дата должна:

- быть заполнена
- быть корректной датой в формате ДД.ММ.ГГГГ

------

## Ошибка

Некорректная дата

------

# 10. Проверка штрих-кода

Штрих-код:

- обязателен
- не может быть пустым

------

## Ошибка

Не указан ШК

------

# 11. Проверка количества

Количество должно:

- быть натуральным числом
- обязателен
- не может быть пустым

------

## Ошибка

Некорректное количество

Не указано количество

------

# 12. Проверка статуса

# Проверка статуса

Статус:

- обязателен
- не может быть пустым

------

## Для операции "Поступление"

Допустимы:

- Ожидает поступления
- Принят

------

## Для операции "Отгрузка"

Допустимы:

- Ожидает отгрузки
- Отгружен

------

## Ошибки

- Не указан статус
- Некорректный статус
- Статус не соответствует типу операции

------

# 13. Проверка клиента

Система должна:

1. найти клиента по названию
2. проверить существование клиента

## Ошибка

Клиент не найден

# 14. Проверка названия

Обязателен

Не может быть пустым

## Ошибка

Не указано название

# 15. Проверка ШК

Обязателен

Не может быть пустым

## Ошибка

Не указан ШК

# 16. Проверка Цвета

Обязателен

Не может быть пустым

## Ошибка

Цвет не найден

# 17. Этап 4 — Проверка бизнес-логики

Запускается только если структура и строки корректны.

------

# 18. Поиск товара

Система должна найти товар в базе.

Название товара НЕ участвует в поиске товара.

Поиск выполняется ТОЛЬКО по:

- ШК
- цвету
- размеру

------

## Для одежды

Поиск по:

- штрих-коду
- цвету
- размеру

------

## Для техники

Поиск по:

- штрих-коду
- цвету (если есть)

---

Название используется только для сверки после нахождения товара.

------

# 19. Результат поиска товара

------

## Если найден один товар

Происходит сверка названия товара с названием товара в строке Excel.

После нахождения товара система сравнивает:

- название из Excel
- название в системе

------

## При несовпадении

Ошибка:

```
Название в системе отличается: [название]
```

------

## Если товар не найден

Ошибка:

Товар не найден

------

## Если найдено несколько товаров

Ошибка:

Найдено несколько вариантов товара

------

# 20. Проверка цвета

Цвет должен:

- быть допустимым для товара

Если у типа товара:

```
учет по цвету = Да
```

цвет обязателен.

Если:

```
учет по цвету = Нет
```

цвет может быть пустым.

------

## Ошибки

- Недопустимый цвет для товара

------

# 21. Проверка размера

Для одежды размер обязателен.

------

## Размер должен

- существовать
- быть допустимым для товара

Если:

```
учет по размеру = Да
```

размер обязателен.

------

## Если:

```
учет по размеру = Нет
```

размер может быть пустым.

------

## Ошибки

- Размер не найден
- Недопустимый размер для товара

------

# 22. Проверка клиента

Товар должен принадлежать клиенту.

------

## Ошибка

Товар не принадлежит клиенту

------

# 23. Проверка остатков

Проверяется только для:

- отгрузок
- со статусом Отгружен

------

# 24. Проверка доступного остатка

Условие:

```
остаток >= количество
```

------

## Ошибка

Недостаточно остатка

------

# 25. Учёт строк внутри файла

Проверка остатков должна учитывать:

- предыдущие строки этого же файла

# Проверка дублей внутри файла

Система должна проверять строки на дублирование.

------

## Строки считаются дублями если совпадают:

- дата
- клиент
- ШК
- цвет
- размер
- статус

------

## Ошибка

```
Дублирующаяся строка в файле
```

------

# 26. Итог проверки

После завершения проверки отображать:

```
Всего строк: 120
Корректных: 110
С ошибками: 10
```

------

# 27. Кликабельность файла

Название и иконка файла должно быть кликабельным.

------

## При нажатии

Раскрывается детализация проверки.

------

# 25. Детализация проверки

------

## Таблица

Показать:

- номер строки
- дата
- штрих-код
- цвет
- размер
- количество
- статус
- найденный товар
- ошибки

------

# 26. Подсветка строк

------

## Корректная строка

Обычное отображение

------

## Строка с ошибкой

Красная подсветка

------

## Строка с предупреждением

Жёлтая подсветка

------

# 27. Ошибки

Ошибки отображаются:

- внутри строки
- текстом
- списком

---

# Приоритет ошибок

Если товар не найден:

НЕ выполнять:

- проверку цвета
- проверку размера
- проверку остатков

# Предупреждения

Предупреждения НЕ блокируют импорт.

Примеры предупреждений:

- Дата операции сильно отличается от текущей
- Необычно большое количество (>5000)

# 28. Кнопки действий

------

## Продолжить импорт

Доступно:

- если нет ошибок

------

## Иконка удалить файл в поле

Удаляет:

- файл
- результаты проверки
- детализацию

------

## Отмена

Возврат назад.

------

# Итоговый статус файла

После проверки файл должен получать один из статусов:

------

## Готов к импорту

Ошибок нет.

------

## Импорт невозможен

Есть ошибки

# 29. Ограничения

На этом этапе запрещено:

- создавать движения
- изменять остатки
- изменять товары

------

# 30. Производительность

Система должна:

- выполнять проверку асинхронно
- минимизировать запросы к базе
- не выполнять отдельный запрос на каждую строку
