# ТЗ для Claude Code: интерфейс «Рейсы поступления» по макетам

> **Визуальный референс:** макеты в дизайн-проекте — `redesign-reisy/index.html`
> (6 артбордов). Перед началом приложи к Claude Code PNG нужного экрана
> (в канвасе: ⋯ на артборде → **Download PNG**) или открой HTML рядом.
> Карта артбордов → экранов ниже.

## Рамки задачи

- Меняем **только фронтенд** слой `ui/` (презентация). **Бэкенд, `tripsApi.ts`,
  схему БД, статусы и переходы НЕ трогаем** — данные те же.
- Соблюдаем слои и правила из `CLAUDE.md` (§4–5): страницы → фичи → primitives,
  справочники только через `useLookups()`, никакого прямого `getDictionary`.
- Переиспользуем существующие primitives (`Badge`, `Card`, `Icon`, `Button`,
  `Input`, `Select`) и токены из `ui/theme.css`. **Новых цветов/шрифтов не
  вводим** — только существующие CSS-переменные.
- Делаем **инкрементально**: один экран = один PR. Порядок — см. в конце.

## Новые общие компоненты (создать в `ui/features/logistics/components/`)

1. **`ProcessRail.tsx`** — вертикальный таймлайн 5 фаз (`draft → awaiting_arrival
   → unloading → costing → closed`). Узел: иконка/✓, заголовок, роль-чип, время
   из `trip_ops` (как `getStatusTimestamps` в текущем `TripStepper`), состояние
   done/active/future. **Заменяет горизонтальный `TripStepper`.**
2. **`RoleChip.tsx`** — `Менеджер` (индиго `--c-accent`) / `Кладовщик`
   (синий `--c-info`). Иконка + подпись.
3. **`PhaseBlock.tsx`** — секция формы: шапка (иконка, заголовок, роль-чип,
   состояние) + тело. `state`: `active` (рамка-акцент) / `locked` (приглушён,
   замок, подпись «заполнит позже») / `done` (read-only сводка).
4. **Стилизованные поля** — `SelectField` (кнопка + поповер с иконками вместо
   голого `<select>`), `MoneyField` (₽-суффикс, моноширинный), `TimeField`
   (иконка календаря). Базируются на существующих primitives/токенах.
5. **`ReceiptCard.tsx`** — карточка поступления: клиент, номер (mono), SKU/шт,
   `Badge` статуса. Заменяет ghost-кнопки в текущем списке.
6. **`CostLedger.tsx`** — план → факт + простой → итого, с отклонением от плана.

## Что реализовать по экранам

### Карточка рейса (общее)
- Шапка: номер (mono) + `Badge` статуса + «сейчас у: `RoleChip`» + контекстная
  главная кнопка с подсказкой о передаче.
- Лэйаут `split` (`1fr / 320px`): слева — фазовые блоки + поступления, справа —
  `ProcessRail` + `CostLedger` + журнал. `TripDetailFeature` делегирует
  по статусу (как `receiptDetail`).
- **Убрать** отдельную карточку `TripReadiness` — заменить на компактный
  чеклист «Готово к передаче» в правой колонке только на `draft`.

### `draft` (менеджер)
- `PhaseBlock` «Планирование» — active, поля через `SelectField`/`MoneyField`/
  `TimeField`. Блоки «Исполнение» и «Закрытие» — `locked` с подписями (показать
  весь путь). Поступления — `ReceiptCard` + «привязать/создать».

### `operator` (кладовщик)
- Отдельный узкий экран-«оператор»: одно крупное действие (кнопка ≥48px)
  «Машина приехала» (`awaiting_arrival`) / «Завершить разгрузку» (`unloading`),
  загруженность сегментами `Полная/Неполная`, список «В машине» (поступления).
- Подсказка про переход поступлений в `on_intake` после разгрузки.

### `costing` (менеджер)
- Прошедшие фазы — `done` (read-only сводка, у «Планирования» — кнопка
  «Изменить транспорт»). Активный блок «Закрытие»: факт + простой + минуты,
  живое «Итого». Справа — `CostLedger` (showActual) + журнал.

### `closed`
- Read-only отчёт: полоса KPI (Итого / Разгрузка / Простой / Загруженность),
  «Маршрут и транспорт», поступления, полный `CostLedger`, журнал.

### Список рейсов
- KPI-полоса (4), чипы-фильтры по статусу, таблица `.t` с колонками:
  Номер, Статус, Откуда, Перевозчик, Клиенты, Поступления, План. прибытие,
  План ₽, Факт ₽.

### Виджет «Мои задачи»
- Очередь по роли+статусу (источники — §7.2 ТЗ), строка: иконка, заголовок,
  номер документа, возраст (просрочка — `--c-danger`), переход. Старые сверху.

## Порядок PR
1. Общие компоненты (`ProcessRail`, `RoleChip`, `PhaseBlock`, поля, `ReceiptCard`,
   `CostLedger`).
2. Карточка рейса по статусам (`draft` → `operator` → `costing` → `closed`).
3. Список рейсов.
4. Виджет «Мои задачи».
