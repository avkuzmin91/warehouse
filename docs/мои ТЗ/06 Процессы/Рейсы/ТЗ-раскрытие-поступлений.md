# ТЗ для Claude Code: раскрытие поступлений в карточке рейса (inline)

> **Визуальный референс:** `redesign-reisy/Раскрытие поступления.html`
> (интерактивный макет: список «Поступления в рейсе», строки раскрываются вниз,
> в каждой строке и в развороте — переход в карточку поступления).
> Перед началом открой его рядом или приложи PNG (демо в `index.html`,
> артборды `expand` / `expand2` / `expand-drawer`).

## Контекст и рамки

- Это **доработка блока «Поступления в рейсе»** в карточке рейса. Сейчас там
  список карточек-поступлений (`ReceiptCard`), по которым нельзя посмотреть состав
  не уходя на отдельную страницу. Нужно дать **раскрытие строки вниз** прямо в
  списке — показать ожидаемые товары (SKU · вариант · план шт) **inline**.
- **Самую карточку поступления НЕ трогаем и НЕ пересобираем.** Переход «открыть
  карточку» ведёт в **уже существующий** экран `ReceiptDetailPage`
  (`/inventory/receipts/:id`) через роутинг. Никакого нового `ReceiptCardPage`,
  никаких копий контента карточки внутри рейса.
- Меняем **только фронтенд** слой `ui/` (презентация). Бэкенд, `tripsApi.ts`,
  `receiptsApi.ts`, схему БД, статусы и переходы — **не трогаем**.
- Соблюдаем слои и правила `CLAUDE.md` (§4–5): страницы → фичи → primitives;
  справочники только через `useLookups()`.
- Переиспользуем существующие primitives (`Card`, `Badge`, `Icon`, `Button`) и
  токены `ui/theme.css`. **Новых цветов/шрифтов нет.**

## Поведение

### Карточка-строка (свёрнута)
Внешне — как текущая `ReceiptCard`, плюс:
- **Шеврон** слева (`chev`, поворот на 90° при раскрытии, transition `200ms`).
- Иконка `inbox` в квадрате 30×30, клиент + номер (mono), строка
  `{sku} SKU · {qty} шт`.
- Справа — `Badge` статуса (если есть) + **кнопка-стрелка** (`arrowRight`,
  `btn ghost icon sm`), которая открывает полную карточку поступления.
  Кнопка скрыта (`opacity:0`), проявляется на hover строки и на `:focus-visible`;
  на тач-устройствах (`@media (hover:none)`) — всегда видна.
- **Основная зона строки (клиент/номер/шеврон) раскрывает/сворачивает** строку
  (`onToggle`). Клик по кнопке-стрелке — `stopPropagation`, он **переходит**, а не
  раскрывает.

### Раскрытие вниз (анимация)
Точно как в макете — без библиотек, через CSS grid:
```css
.exp-wrap   { display: grid; grid-template-rows: 0fr;
              transition: grid-template-rows 240ms cubic-bezier(.32,.72,0,1); }
.exp-wrap.open { grid-template-rows: 1fr; }
.exp-inner  { overflow: hidden; min-height: 0; }
```
При раскрытии: рамка карточки → `--c-border-strong`, шапка строки →
фон `--c-bg-sunken`. Несколько строк могут быть открыты одновременно
(состояние — `Set` открытых id).

### Развёрнутое тело
Внутри `.exp-inner`, с отступом и `border-top`:
1. **`ReceiptLinesTable`** — таблица ожидаемых товаров:
   - шапка-колонки: `№` · `SKU · товар` · `план, шт` (uppercase, faint, 10.5px);
   - строка: номер (mono, faint), название товара + вариант (faint, если есть),
     под названием — SKU (mono, 10.5px faint), справа план-шт (mono, tabular-nums);
   - футер: `Итого` слева, `{N} SKU · {qty} шт` справа (числа — mono, bold),
     отделён `1.5px solid --c-border-strong`.
2. **Подвал-CTA** (через `1px dashed --c-border`): текст
   «Нужны реквизиты, приёмка, брак?» + кнопка `[Открыть карточку поступления]`
   (`btn sm`, иконки `inbox` + `arrowRight`) — **вторая точка входа** в ту же
   карточку поступления.

### Переход в карточку
- Обе точки входа (стрелка в строке + кнопка в развороте) делают
  `navigate('/inventory/receipts/' + receipt.id)` — роут уже существует
  (`ReceiptDetailPage`). **Ничего из карточки здесь не рендерим.**
- Если рейс открыт в шторке/модалке — навигация должна её корректно закрывать
  (используй текущий паттерн перехода со страницы рейса; если его нет — спроси,
  не выдумывай).

### Шапка блока
- Заголовок «Поступления в рейсе», справа — `{N} поступления · {qty} шт`.
- Кнопка **«Развернуть все / Свернуть все»** (`btn ghost sm`, иконка
  `chevDown`/`chevUp`) — тоггл всего `Set`.
- Подпись-хинт внизу блока (faint, иконка `alert`): «Стрелка → открывает полную
  карточку поступления».

## Данные

- Строки тянем **по требованию** — лениво при первом раскрытии строки (или сразу,
  если состав уже есть в payload рейса). Используй **существующий** хук из
  `receiptsApi`: вероятно `useReceiptItems(receiptId)` / `useReceipt(id).items`.
  - если строки уже приходят внутри `useTrip(tripId)` (вложенные `receipts[].items`)
    — бери оттуда, **без лишнего запроса**;
  - если отдельного хука/поля нет — **не выдумывай endpoint, спроси меня.**
- Поля строки: `sku`, `name`, `variant` (опц.), `qty` (план). `Итого` считаем на
  клиенте.
- Состояния раскрытого тела: `loading` → 3 строки-скелетона в таблице;
  `empty` → «Строки не заданы — состав появится на приёмке» (faint, иконка `inbox`);
  `error` → компактный inline-`EmptyState tone="danger"` с повтором.

## Правила

- Раскрытие — **чисто презентационное**, никаких мутаций.
- Состояние открытых строк держим локально во вью (`Set<receiptId>`); сбрасывать
  при смене рейса. По желанию — запоминать в URL/`localStorage`
  (`ui.trip.<id>.openReceipts`), но это не обязательно.
- Доступность: основная зона и кнопка — `<button>`; `aria-expanded` на тоггле,
  шеврон `aria-hidden`. Раскрытие работает с клавиатуры (Enter/Space).
- Уважать `prefers-reduced-motion`: при `reduce` — без transition высоты.
- Стили — только классы `theme.css` + точечный inline для grid/таблицы; новые
  правила `.exp-wrap/.exp-inner/.exp-open-btn` положить в `theme.css` (не в JSX).

## Definition of Done

- В карточке рейса строки «Поступлений в рейсе» раскрываются вниз с плавной
  анимацией; видно состав (SKU · вариант · план шт) + «Итого», как в
  `Раскрытие поступления.html`.
- «Развернуть все / Свернуть все» работает; несколько строк открываются разом.
- Стрелка в строке и кнопка в развороте ведут в **существующую**
  `ReceiptDetailPage` (`/inventory/receipts/:id`) — карточка не пересобиралась.
- `rg "ReceiptCardPage|ReceiptDetail" ui/features/logistics` — нет нового
  дублирующего экрана карточки внутри рейса (только навигация по роуту).
- API/типы (`tripsApi.ts`, `receiptsApi.ts`) не менялись; только токены `theme.css`;
  пройдены `eslint` и `tsc`.
