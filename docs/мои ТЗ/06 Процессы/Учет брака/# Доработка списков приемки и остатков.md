# Задача

Необходимо доработать отображение количества в списках поступлений и отгрузок.

Перед выполнением изучи:

- List Page Pattern
- Table component
- существующие таблицы поступлений
- существующие таблицы отгрузок
- UI паттерны карточек и KPI
- текущую структуру колонок

Использовать существующие глобальные компоненты системы.

Не изменять архитектуру таблиц.
Не изменять глобальный компонент Table.
Не создавать отдельные страницы.
Не использовать модальные окна.

Необходимо изменить только визуализацию содержимого ячеек.

---

# Контекст

Сейчас:

в списке поступлений отображается:

| Количество |
| ---------- |
| 100        |

в списке отгрузок:

| Остаток |
| ------- |
| 100     |

После внедрения проверки качества этого недостаточно.

Пользователь не понимает:

- сколько товара всего
- сколько выявлено брака
- какой процент уже проверен

Для WMS это критично.

Нужен компактный информативный формат прямо внутри строки таблицы.

Стиль:

SaaS / ERP / WMS dashboard

---

# Требование

Заменить простое числовое отображение на компактный информационный блок внутри ячейки таблицы.

Вместо:

```text
100
```

Использовать формат:

```text
100 шт
Брак: 5
Проверено: 60%

██████░░░░
```

или:

```text
100 шт

5 брак • 60%

████████░░
```

Компонент должен занимать минимум места.

Высота строки таблицы должна увеличиваться минимально.

---

# Список поступлений

Изменить колонку:

```text
Количество
```

Отображать:

1. крупное значение:

```text
100 шт
```

2. вторичная строка:

```text
Брак: 5
```

3. процент проверки:

```text
Проверено: 60%
```

4. progress bar

Формула:

```text
проверено / всего *100
```

---

# Список отгрузок

Сейчас используется колонка:

```text
Остаток
```

Изменить отображение.

Показывать:

1. Всего:

```text
100 шт
```

2. Брак:

```text
Брак: 8
```

3. Процент проверки:

```text
Проверено: 92%
```

4. progress bar

---

# Визуальные требования

Основное количество:

- font-weight: semibold
- размер больше вторичного текста

Вторичная информация:

- маленький текст
- muted color

Брак:

- красный индикатор или badge

Процент проверки:

- нейтральный цвет

---

# Progress bar

Требования:

- компактный
- высота 4–6px
- скругления
- использовать системный primary color

Пример:

```text
████████░░
```

---

# Поведение

Если:

брак = 0

показывать:

```text
Без брака
```

или скрывать строку.

---

Если:

проверено =100%

показывать:

```text
Проверено 100%
```

и заполненный progress.

---

Если:

проверено =0

показывать:

```text
Не проверено
```

# Ограничения

Запрещено:

- менять глобальный Table
- менять List Page Pattern
- использовать tooltip как основной способ отображения
- добавлять новые страницы
- использовать тяжелые chart библиотеки
- увеличивать строку таблицы более чем в 1.5 раза

---

# Ожидаемый результат

Сгенерировать:

1. JSX структуры ячейки
2. переиспользуемый компонент количества
3. использование для поступлений
4. использование для отгрузок
5. описание состояний
6. итоговый визуальный результат

Компонент должен быть переиспользуемым.
Например:

```tsx
<QuantitySummary
 total={100}
 defect={5}
 checked={60}
/>
```

и использоваться в обеих таблицах.
