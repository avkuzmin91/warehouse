# Задача

Необходимо доработать поле "Количество" в карточке создания/редактирования поступления.

Изучи существующие:

- глобальные UI компоненты
- Entity Page Pattern
- стили карточек
- Form Pattern
- дизайн остальных форм системы

Используй существующую дизайн-систему и компоненты.

Не создавать отдельную страницу.
Не использовать модальные окна.
Не ломать текущую структуру формы.

---

# Контекст

Сейчас количество указывается обычным числовым полем:

```text
Количество: [100]
```

Для поступлений с большим объемом товара это неудобно.

Пользователь не получает визуальный контекст:

- сколько ожидается
- сколько принято
- сколько проверено
- сколько брака
- сколько осталось

После внедрения проверки качества поле должно стать частью информационного блока.

Необходимо сделать визуально более понятный и современный компонент.

Стиль:

SaaS / WMS / dashboard

---

# Требование

Поле количества должно быть преобразовано в отдельный визуальный блок.

Пример структуры:

```text
┌──────────────────────────────┐
Количество товара
100 шт
──────────────────────────────
Всего поступило:      100
Проверено:             60
Брак:                   5
Не проверено:          35
──────────────────────────────
████████░░░░░ 60%
Проверено
└──────────────────────────────┘
```

---

# UI требования

Использовать Card UI.

Требования:

- скругления как в системе
- мягкая тень
- внутренние отступы
- адаптивность
- визуально выглядит как KPI карточка

---

# Состав блока

Верхняя часть:

Название:

```text
Количество товара
```

Ниже:

Крупное значение:

```text
100 шт
```

Размер больше обычного текста.

---

# Информационные показатели

Отображать:

- Всего поступило
- Проверено
- Брак
- Не проверено

Требования:

- компактное расположение
- значения справа
- одинаковое выравнивание

Пример:

```text
Всего поступило       100
Проверено              60
Брак                    5
Не проверено           35
```

---

# Прогресс

Добавить progress bar.

Логика:

```text
процент = проверено / поступило
```

Пример:

60 из 100

↓

60%

---

# Цвета

Проверено:

зелёный

Брак:

красный

Не проверено:

серый или жёлтый

Прогресс:

использовать системный primary color

---

# Поведение

Создание поступления:

Показывать:

```text
Количество товара
100 шт
```

остальные поля:

```text
0
```

---

После приемки:

обновлять данные автоматически.

---

обновлять:

- проверено
- брак
- не проверено
- прогресс

Без перезагрузки страницы.
