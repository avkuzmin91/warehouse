# **COMPONENT: Product Variants Editor**

---

# 1. Цель

Реализовать механизм редактирования вариантов товара (SKU),

где один товар содержит:

- несколько цветов
- несколько габаритов
- несколько размеров (опционально)

---

# 2. Концепция

Товар делится на:

1. Родительскую сущность (Product)

2. Варианты (Product Variants)

---

## Формула варианта:

Variant = Цвет + Габарит + Размер (опционально)

---

# 3. Data Model (расширение)

## Product

{
 id: string
 name: string
 type_id: string
 sku: string
 client_id: string

is_active: boolean
 }

---

## ProductVariant

{
 id: string
 product_id: string

color_id: string

dimension: {
 length: number
 width: number
 height: number
 }

size_id: string | null
 }

---

# 4. Где используется

- EDIT PAGE товара
- VIEW PAGE товара

---

# 5. UI структура

В карточке товара добавляется блок:

Варианты товара

---

## Структура блока:

# 6. Таблица вариантов

Колонки:

1. Цвет
2. Габариты (Д×Ш×В)
3. Размер (если есть)
6. Действия

------

## Особенности:

- строки НЕ ведут на отдельную страницу
- редактирование inline (разрешено здесь)

------

# 7. Редактирование варианта

------

## Можно изменять:

- color_id
- dimension
- size_id

------

## Нельзя:

- менять product_id
- ломать уникальность комбинации

------

# 8. Уникальность

Каждый вариант должен быть уникален по:

```
color_id + dimension + size_id
```

------

# 9. Добавление варианта

Кнопка:

```
Добавить вариант
```

------

## Поведение:

- добавляется новая строка
- поля пустые / default
- пользователь заполняет

------

# 10. Удаление варианта

В каждой строке:

- кнопка удаления

------

## Поведение:

- либо remove (по решению backend)

------

# 11. Массовая генерация (ВАЖНО)

------

## При создании товара:

варианты создаются автоматически

------

## При редактировании:

массовая генерация НЕ используется

------

пользователь управляет вариантами вручную

------

# 13. Поведение загрузки

------

## При открытии EDIT:

```
GET /products/{id}
GET /products/{id}/variants
```

------

## При сохранении:

### Варианты отправляются отдельно:

```
PATCH /products/{id}/variants
```

------

# 14. Валидация

------

## Проверяется:

- color_id обязателен
- dimension обязателен
- size_id обязателен (для одежды)
- уникальность комбинации

------

# 15. UI состояния

------

## Loading

- skeleton таблицы

------

## Empty

- сообщение:
   "Нет вариантов"
- кнопка "Добавить вариант"

------

## Error

- сообщение + retry

------

# 16. Ограничения

- нельзя редактировать варианты вне карточки
- нельзя создавать варианты без товара
- нельзя дублировать комбинации

------

# 17. UX логика

------

## Пользователь:

1. Открывает товар
2. Видит список вариантов
3. Может:
   - изменить
   - удалить
   - добавить

------

# 18. Связь с другими компонентами

Использует:

- Table
- Form controls
- File Upload
- SystemInfoBlock (опционально)

------

# 19. Итог

Product Variants Editor:

- превращает товар в **набор SKU**
- даёт полный контроль над комбинациями
- отделяет массовое создание от ручного редактирования
