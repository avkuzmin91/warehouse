Реализовать отображение версии и окружения системы в интерфейсе.

## Требование

В футере приложения необходимо отображать текущую версию системы и окружение.

---

## Логика формирования версии системы

### 1. Формат версии

Версия системы формируется в формате:

```
MAJOR.MINOR.PATCH
```

Начальная версия системы:

```
1.0.1
```

---

### 2. Правила изменения версии

#### MAJOR (первое число)

Меняется при:

* крупных изменениях архитектуры
* несовместимых изменениях API
* переработке ключевых модулей системы

#### MINOR (второе число)

Меняется при:

* добавлении новой функциональности
* расширении существующего функционала
* изменениях, не ломающих совместимость

#### PATCH (третье число)

Меняется при:

* исправлении ошибок
* мелких доработках
* технических правках без изменения логики

---

### 3. Принцип увеличения версии

* при релизе изменения выбирается только один уровень увеличения:

  * либо MAJOR
  * либо MINOR
  * либо PATCH
* более младшие разряды сбрасываются:

  * при увеличении MAJOR → MINOR и PATCH = 0
  * при увеличении MINOR → PATCH = 0

Пример:

* было: 1.4.2
* минорный релиз → 1.5.0
* патч → 1.4.3
* мажорный релиз → 2.0.0

---

### 4. Привязка к окружению

Версия отображается вместе с окружением:

```
v1.4.2 (dev)
```

Окружения:

* dev — разработка
* test — тестирование
* prod — рабочая среда

---

### 5. Источник данных

* версия формируется в процессе сборки или передаётся из backend
* окружение берётся из конфигурации системы (переменные окружения или настройки сборки)
* frontend только отображает полученные данные

---

### 6. Отображение в интерфейсе

* отображается в футере на всех страницах
* формат:

```
vX.Y.Z (environment)
```

* пример:

```
v1.0.1 (test)
```

---

### 7. Требования к поведению

* версия и окружение не редактируются пользователем
* обновляются только при новом деплое или смене конфигурации
* не влияют на бизнес-логику приложения

---

## Ожидаемый результат

В футере всегда отображается актуальная информация:

* текущая версия системы по правилам семантического версионирования
* текущее окружение (dev / test / prod)
