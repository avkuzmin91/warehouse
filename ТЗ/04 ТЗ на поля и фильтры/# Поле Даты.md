# Спецификация UX/UI для поля выбора даты (без времени)

## Область применения

Поле используется для выбора **одной календарной даты без времени**:

- дата доставки
- дата рождения
- дата бронирования
- любые атрибуты с типом Date

------

# 1. Базовый паттерн

Используется:
→ **input + date picker (календарь)**

### Почему

- исключает ошибки формата
- быстрее ручного ввода
- привычный паттерн

------

# 2. Структура компонента

## 2.1 Поле ввода

- Формат отображения: `DD.MM.YYYY` (локализуемый)
- Плейсхолдер: `дд.мм.гггг`
- Иконка календаря справа
- Кнопка очистки (×) при наличии значения

Пример:

[ 12.03.2026 📅 × ]

------

## 2.2 Date picker (календарь)

Открывается:

- по клику на поле
- по клику на иконку

Отображает:

- месяц + год
- сетку дней (7 колонок)

------

# 3. Поведение

## 3.1 Выбор даты

- Клик по дню:
  → выбирает дату
  → закрывает календарь
  → подставляет значение в input

------

## 3.2 Навигация

- Переключение месяцев (← →)
- Быстрый выбор года/месяца (dropdown или переключение вида)

------

## 3.3 Ограничения (если есть)

Поддержка:

- minDate (минимальная дата)
- maxDate (максимальная дата)
- disabledDates (конкретные даты)

Недоступные даты:

- визуально задизейблены
- не кликабельны

------

## 3.4 Очистка

- Клик по «×» очищает значение
- aria-label: «Очистить дату»

------

## 3.5 Ручной ввод (опционально)

Если включён:

- Маска: `DD.MM.YYYY`
- Автоподстановка разделителей
- Валидация при вводе
- Невалидная дата → ошибка

Если выключен:

- поле readonly

------

# 4. Валидация

Ошибки:

- неверный формат
- несуществующая дата (31.02)
- вне допустимого диапазона

Отображение:

- текст ошибки под полем
- подсветка поля

------

# 5. Клавиатура

- Enter → открыть календарь
- Esc → закрыть
- Tab → переход
- Стрелки → навигация по дням (если открыт календарь)

------

# 6. Доступность (Accessibility)

- role="textbox" + aria-haspopup="dialog"
- календарь = dialog / grid
- дни = button
- aria-selected для выбранной даты
- поддержка screen reader

------

# 7. Мобильная версия

- Bottom sheet или нативный picker (если допустимо)
- Крупные зоны нажатия (≥ 44px)
- Фиксированная панель:
  - «Отмена»
  - «Применить» (если выбор не мгновенный)

------

# 8. Улучшения (опционально)

## 8.1 Быстрые действия

- Сегодня
- Завтра
- +7 дней

------

## 8.2 Подсветка

- текущий день (today)
- выбранный день
- hover диапазон

------

# 9. Антипаттерны

- Только ручной ввод без календаря
- Нет валидации
- Сложный выбор года (по одному месяцу листать 20 лет)
- Маленькие кликабельные зоны

------

# 10. Переиспользуемость

Пропсы:

- value: Date | null
- onChange: (date: Date | null) => void
- minDate?: Date
- maxDate?: Date
- disabledDates?: Date[]

Дополнительно:

- locale
- format
- readonly

------

# 11. Форматы

Рекомендуемый:

- RU: DD.MM.YYYY
- EN: MM/DD/YYYY или ISO (YYYY-MM-DD)

Хранение:
→ ISO 8601 (`YYYY-MM-DD`)

------

# 12. Технологии

- React
- date-fns / dayjs
- Headless UI или кастомный календарь

------
